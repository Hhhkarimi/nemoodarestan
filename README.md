# نمودارستان

**از داده تا تصویر، به فارسی.** کتابخانهٔ قابل گسترش ابزارهای ساخت نمودار با رابط راست‌به‌چپ و پردازش داده در مرورگر.

| ابزار | کاربرد | مسیر |
|---|---|---|
| سانکی | جریان بودجه، انرژی و مسیر کاربر | `/studio/sankey` |
| ورونوی | سهم دسته‌ها و ترکیب داده | `/studio/voronoi` |
| کورد | ارتباط و تبادل میان گروه‌ها | `/studio/chord` |
| نقشهٔ ایران | دادهٔ استانی و شهرستانی | `/studio/iran-map` |

ویرایشگرها به‌طور کامل در همین ریپو قرار دارند و همراه سایت ساخته می‌شوند. هیچ ابزار از دامنهٔ خارجی در iframe بارگذاری نمی‌شود.

## اجرا

به Node.js نسخهٔ ۲۴ نیاز دارید.

```sh
npm ci
npm run install:studios
npm run dev
```

سایت در `http://127.0.0.1:4317` در دسترس است. برای تغییر پورت، متغیر `PORT` را تنظیم کنید.

```sh
npm run check
npm run test:studios
npm run build
npm run preview
```

برای ویرایش سریع گالری، `npm run dev:gallery` را اجرا کنید. این حالت فقط پوستهٔ گالری را با HMR اجرا می‌کند. برای بررسی هر چهار ابزار، از `npm run dev` یا `npm run preview` استفاده کنید.

## انتشار روی Vercel

[ایمپورت ریپو در Vercel](https://vercel.com/new)

ریپو را در Vercel ایمپورت کنید و Root Directory را روی ریشهٔ ریپو نگه دارید. فایل `vercel.json` همهٔ تنظیمات را تعیین می‌کند:

- Install: `npm ci && npm run install:studios`
- Build: `npm run build`
- Output: `dist`
- Node.js: `24.x`
- بدون نیاز به دیتابیس یا متغیر محیطی

برای اتصال همین ریپو به دیپلوی خودکار، از بخش New Project → Import Git Repository استفاده کنید. پس از اتصال، هر push به `main` دیپلوی جدید می‌سازد.

## افزودن نمودار

کد ابزار را در `apps/<id>` قرار دهید؛ سپس تنها یک رکورد به `catalog.json` اضافه کنید. گالری، راهنمای انتخاب، فهرست تغییر ابزار و اسکریپت ساخت از همین فایل تغذیه می‌شوند. [راهنمای کامل توسعه](docs/adding-a-chart.md) را ببینید.

## ساختار

```text
catalog.json          فهرست مرکزی نمودارها و تنظیمات ساخت
src/                  گالری و پوستهٔ ویرایشگر
tokens.css            توکن‌های طراحی گالری
apps/                 کد کامل ویرایشگرها با lockfile مستقل
public/previews/      پیش‌نمایش‌های SVG واقعی با دادهٔ نمونه
scripts/              نصب، ساخت و سرور پیش‌نمایش
tests/                بررسی قرارداد ثبت ابزار و تنظیمات استقرار
docs/                 توسعه، منابع و آزمون پذیرش
dist/                 خروجی همهٔ ابزارها برای یک دیپلوی
```

گالری با TypeScript و Vite ساخته شده است. ابزارها build مستقل دارند و زیر `/studios/<id>/` قرار می‌گیرند. پوسته در `/studio/<id>` ویرایشگر هم‌دامنه را نمایش می‌دهد تا CSS و وابستگی‌های چهار پروژه با هم تداخل نکنند. پیوند «باز کردن مستقل ویرایشگر» برای استفادهٔ تمام‌صفحه نیز موجود است.

## حریم خصوصی و ذخیرهٔ کار

سرور یا API دریافت داده وجود ندارد. ورود و پردازش فایل در مرورگر انجام می‌شود. هر ابزار کلید ذخیرهٔ محلی مخصوص خودش را دارد. ذخیره‌های دامنه‌های قبلی به این دامنه منتقل نمی‌شوند؛ فایل پروژه را در ابزار قبلی خروجی بگیرید و در ابزار جدید باز کنید. برای نگهداری مطمئن کار، از امکان ذخیرهٔ پروژه در خود ابزار استفاده کنید.

## ساخت در محیط محدود

اگر محیط اجازهٔ اجرای پردازش‌های فرزند یا کامپایلرهای بومی را نمی‌دهد، پس از نصب وابستگی‌ها می‌توان از `npm run build:portable` استفاده کرد. این مسیر از WebAssembly و JavaScript استفاده می‌کند؛ بررسی TypeScript را جداگانه اجرا کنید. Vercel و CI از مسیر استاندارد `npm run build` استفاده می‌کنند.
