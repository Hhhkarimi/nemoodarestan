# منابع و تصمیم‌های یکپارچه‌سازی

آدرس و نسخهٔ هر چهار منبع در `catalog.json` ثبت شده است. کدها به‌صورت snapshot داخل ریپو نگهداری می‌شوند؛ هنگام build نیازی به خواندن ریپوهای GitHub نیست. تغییرات آیندهٔ ریپوهای اصلی خودکار وارد این نسخه نمی‌شوند.

- [سانکی استودیو](https://github.com/Hhhkarimi/sankey-studio)
- [ورونوی استودیو](https://github.com/Hhhkarimi/voronoi-treemap-studio)
- [کورد استودیو](https://github.com/Hhhkarimi/chord-diagram)
- [نقشه‌ساز ایران](https://github.com/Hhhkarimi/IranMapStudio)

تغییرات محدود روی منابع:

- دریافت فونت خروجی سانکی و ورونوی نسبت به سند همان ویرایشگر انجام می‌شود.
- آدرس favicon ورونوی نسبی شده است.
- نویسندهٔ خروجی build کورد، فایل‌ها را در `dist/assets` می‌نویسد تا تفاوت مسیر Windows و Linux باعث جابه‌جایی خروجی نشود.
- مسیر پایهٔ Vite هنگام ساخت از رکورد هر نمودار گرفته می‌شود.

ابزارها به دلیل تفاوت در چارچوب و CSS در سند هم‌دامنهٔ مستقل نمایش داده می‌شوند. این تصمیم قابلیت‌های موجود را حفظ می‌کند و امکان مهاجرت تدریجی ابزارها به یک رابط مشترک را باقی می‌گذارد. بخش‌های داخلی چهار ویرایشگر هنوز طراحی و رفتار پروژهٔ اصلی خود را دارند.

دادهٔ مرزی نقشهٔ ایران از `react-iran-maps` با مجوز MIT و تقسیمات ۱۴۰۰/۲۰۲۱ آمده است. پیش‌نمایش نقشه نیز از همین داده تولید شده است؛ مرزها ادعای به‌روزبودن تقسیمات اداری ندارند.

فونت Vazirmatn با SIL Open Font License استفاده می‌شود. فایل `public/fonts/OFL.txt` و مجوزهای داخل `apps` حفظ شده‌اند. ریپوهای سانکی و ورونوی در نسخهٔ منبع مجوز کلی جداگانه ندارند؛ این یکپارچه‌سازی مجوز آن منابع را تغییر نمی‌دهد.
