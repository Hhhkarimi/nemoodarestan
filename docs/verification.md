# گزارش بررسی نسخهٔ اول

تاریخ بررسی: ۱۶ اکتبر ۲۰۲۶

## ساخت و بررسی خودکار

ساخت استاندارد روی Ubuntu با Node.js 24 در [GitHub Actions](https://github.com/Hhhkarimi/nemoodarestan/actions/runs/38873187942) موفق بود. مراحل نصب lockfileها، بررسی TypeScript گالری، تست قرارداد کاتالوگ، تست‌های سانکی/ورونوی/کورد و ساخت همهٔ ابزارها اجرا شدند. خروجی واقعی همین build برای بررسی در مرورگر دریافت شد.

TypeScript هر چهار ابزار در محیط محلی هم بدون خطا بررسی شد. ساخت WebAssembly محلی نیز موفق بود؛ این مسیر برای دورزدن محدودیت اجرای subprocess در محیط آزمایش استفاده شد، نه برای جایگزینی build استاندارد Vercel.

## بررسی در مرورگر

| مورد | نتیجه |
|---|---|
| فونت Vazirmatn و چهار پیش‌نمایش SVG | بارگذاری موفق |
| جست‌وجوی فارسی با حروف عربی (`سانكي`) | یافتن سانکی |
| جست‌وجوی انگلیسی و بازبارگذاری URL | حفظ عبارت و نتایج |
| دسته‌بندی جریان | نمایش سانکی و کورد |
| عبارت بدون نتیجه و بازنشانی | پیام مناسب و بازیابی همه |
| راهنمای انتخاب، Escape و نسخهٔ موبایل | باز و بسته‌شدن صحیح |
| تغییر ابزار از سربرگ | بازشدن مسیر مستقل ابزار |
| آدرس ابزار نامعتبر | صفحهٔ بازیابی و بازگشت به کتابخانه |
| تغییر داده در هر چهار ابزار | تغییر مقدار قابل مشاهده در نمودار |
| دریافت SVG سانکی، ورونوی و کورد | پیام موفقیت ویرایشگر |
| دریافت PNG ورونوی و کورد | پیام موفقیت ویرایشگر |
| دکمه‌های SVG و PNG نقشه | اجرا بدون پیام خطای ابزار |
| منابع HTML خروجی استاندارد | پنج صفحه، بدون ارجاع به فایل مفقود |

محتوای فایل‌های دانلودشده مستقل از مرورگر بازبینی نشده است. PNG سانکی تا مرحلهٔ آغاز آماده‌سازی اجرا شد؛ ثبت موفقیت نهایی آن در این بررسی انجام نشده است.

## نمایش واکنش‌گرا

گالری در عرض‌های ۳۲۰، ۳۷۵، ۴۱۴، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شد؛ هیچ عنصر بیرون‌زده یا اسکرول افقی مشاهده نشد. تصویر دسکتاپ و موبایل ثبت شده است. نقشه و سربرگ مشترک نیز در عرض ۳۷۵ پیکسل بازبینی تصویری شدند. بررسی کامل همهٔ کنترل‌های داخلی چهار ابزار در تمام اندازه‌ها انجام نشده است.

## انتشار

فایل `vercel.json` آماده است. وضعیت دیپلوی نهایی وابسته به ورود مالک حساب Vercel است؛ موفقیت build به معنی انتشار سایت نیست.
