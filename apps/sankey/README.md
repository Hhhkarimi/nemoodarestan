# سانکی استودیو | Sankey Studio

وب‌اپ فارسی و راست‌به‌چپ ساخت سانکی با پیش‌نمایش زنده؛ الهام‌گرفته از [نقشه‌ساز ایران](https://iran-map-studio.vercel.app/).

داده‌ها و فونت‌های شخصی در مرورگر پردازش می‌شوند. نیازی به سرور، کلید API یا حساب کاربری نیست.

## امکانات

- ورود داده از جدول، متن، CSV، TSV، Excel و JSON؛ انتخاب شیت و تطبیق ستون‌ها.
- چهار نمونه قابل ویرایش: مالی، انرژی، مسیر کاربران و جریان مواد تولید.
- تنظیم عنوان، زیرعنوان، واحد، جهت، تراز، مرتب‌سازی و ابعاد بوم.
- پنج پالت، گرادیان، رنگ اختصاصی هر گره و جریان، عرض و فاصله گره‌ها، انحنا و شفافیت.
- تنظیم نام و مقدار گره‌ها، درصد ورودی، اعداد فارسی/انگلیسی و اعشار.
- فونت WOFF2، WOFF، TTF و OTF؛ انتخاب فونت و حفظ آن در پروژه و خروجی SVG/PNG/JPG.
- جابه‌جایی گره‌ها، بزرگ‌نمایی، نمای ارائه، حالت تاریک، واگرد و بازانجام.
- PNG شفاف، JPG، SVG با فونت تعبیه‌شده، HTML نمودار، Excel، CSV و پروژه JSON.
- PDF از چاپ مرورگر؛ ذخیره خودکار محلی و رابط واکنش‌گرا.

## دیپلوی روی Vercel

1. در Vercel یک پروژه جدید بسازید و مخزن **Hhhkarimi/sankey-studio** را Import کنید.
2. Root Directory را در ریشه مخزن نگه دارید (`.`).
3. `vercel.json` تنظیمات را مشخص می‌کند:
   - Framework: **Vite**
   - Install Command: `npm ci`
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Node.js: **24.x** مطابق `package.json` و `.nvmrc`
4. Deploy را بزنید؛ متغیر محیطی لازم نیست.

مخزن برای دیپلوی آماده است؛ ایجاد پروژه Vercel یا انتشار آن بخشی از این ثبت نیست. [راهنمای رسمی](https://vercel.com/docs/frameworks/frontend/vite).

## توسعه محلی

```sh
npm ci
npm run dev
npm run build
npm run preview
npm test
```

برای Windows محدود که اجرای پردازش فرزند را منع می‌کند:

```sh
node node_modules/typescript/bin/tsc --noEmit
node scripts/vite-local.mjs
node scripts/serve.mjs
```

فایل HTML مستقل پس از ساخت portable با `node scripts/standalone.mjs` در کنار پوشه پروژه ساخته می‌شود. بیلد عادی Vercel از Vite استاندارد استفاده می‌کند.

## قالب داده

```csv
source,target,value
فروش,درآمد,100
درآمد,هزینه,60
درآمد,سود,40
```

متن: `فروش [۱۰۰] درآمد`. JSON: آرایه ردیف‌های `source`, `target`, `value` یا فایل پروژه ذخیره‌شده.

## رفتار و محدودیت‌ها

مقدار جریان باید مثبت و مسیرها بدون حلقه باشند. حداکثر فایل داده ۱۰ مگابایت و پروژه ۱۰۰۰ جریان دارد. مقدار گره برابر بیشینه مجموع ورودی و خروجی آن است؛ اختلاف ورودی و خروجی هشدار می‌گیرد. مجموع نمودار مجموع ورودی ریشه‌هاست و جریان میانی دوباره شمرده نمی‌شود. درصدها نسبت به همین مجموع هستند و بین مراحل قابل جمع‌زدن نیستند.

حداکثر هر فونت ۲ مگابایت و مجموع فایل‌های فونت حدود ۳ مگابایت است. ذخیره خودکار به ظرفیت و مجوز مرورگر وابسته است؛ JSON پروژه مستقل از آن است. فونت سیستمی ممکن است در دستگاه دیگر متفاوت باشد؛ برای خروجی قابل انتقال از وزیرمتن یا فونت بارگذاری‌شده استفاده کنید.

## ساختار و مجوزهای کتابخانه‌ها

`src/model.ts`: مدل و اعتبارسنجی. `src/chart.ts`: D3 و SVG. `src/fonts.ts`: بارگذاری و تعبیه فونت. `src/main.ts`: رابط، فایل‌ها، ذخیره و تاریخچه.

فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) با SIL Open Font License؛ مجوز در `public/fonts/LICENSE.txt`. چیدمان با d3-sankey، Excel با SheetJS و آیکن‌ها با Lucide.
