# رودخانه‌ای استودیو

ویرایشگر فارسی Streamgraph با دادهٔ دستی/فایلی، فونت دلخواه، چیدمان‌های wiggle/silhouette/zero، سهم درصدی و خروجی تصویری.

از ریشهٔ نمودارستان، `npm ci` و `npm run install:studios` را اجرا کنید. این ابزار از وابستگی‌ها و ماژول مشترک ریشه استفاده می‌کند. برای توسعهٔ مستقل رابط: `npm --prefix apps/streamgraph run dev`.

[قالب داده، امکانات و روش محاسبه](../../docs/series-studios.md).
