# کوهستانی استودیو

ویرایشگر فارسی Ridgeline / Joyplot با برآورد چگالی گاوسی وزن‌دار، پهنای خودکار یا دستی، هم‌پوشانی، خط میانه، فونت دلخواه و خروجی تصویری.

از ریشهٔ نمودارستان، `npm ci` و `npm run install:studios` را اجرا کنید. این ابزار از وابستگی‌ها و ماژول مشترک ریشه استفاده می‌کند. برای توسعهٔ مستقل رابط: `npm --prefix apps/ridgeline run dev`.

[قالب داده، امکانات و روش محاسبه](../../docs/series-studios.md).
