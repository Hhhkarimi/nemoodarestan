# کورد استودیو

وب‌اپ فارسی رسم **Chord Diagram** با الهام از [سانکی استودیو](https://sankey-studio.vercel.app/). داده‌ها در مرورگر پردازش می‌شوند و سرویس سرور لازم نیست.

## اجرا

به Node.js نسخهٔ ۲۴ یا جدیدتر نیاز دارید. ساخت با TypeScript و esbuild WebAssembly انجام می‌شود. پیش‌نمایش پیش‌فرض در `http://127.0.0.1:4173` است؛ برای تغییر درگاه متغیر محیطی `PORT` را تنظیم کنید. پس از ویرایش سورس، دوباره برنامه را بسازید و صفحه را تازه کنید.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

نسخه تولید در `dist/` ساخته می‌شود. در Vercel مخزن را Import کنید؛ تنظیمات ساخت در `vercel.json` موجود است. هر میزبان فایل استاتیک نیز پشتیبانی می‌شود.

## امکانات

- رابط راست‌به‌چپ، وزیرمتن محلی، اعداد فارسی و انگلیسی و دقت اعشار
- جدول قابل ویرایش، ورود متن، CSV / TSV / JSON و نمونه‌های آماده
- Chord معمولی و جهت‌دار، حلقه و ارتباط دوطرفه، تجمیع ردیف‌های تکراری
- پالت و رنگ اختصاصی گروه‌ها، گرادیان، شعاع، فاصله، ضخامت، چرخش و شفافیت
- عنوان، زیرعنوان، واحد، برچسب، مقدار، درصد، راهنمای رنگ و ابعاد بوم
- تغییر اندازه عنوان و برچسب؛ بارگذاری TTF، OTF، WOFF و WOFF2
- خروجی SVG، PNG و JPG؛ شفافیت، کیفیت ۱/۲/۴ برابر و چاپ PDF مرورگر
- جاسازی فونت در خروجی، ذخیره پروژه همراه فونت، بازیابی محلی، واگرد و بازانجام
- تمرکز روی گروه، بزرگ‌نمایی، تمام‌صفحه، حالت تاریک و طراحی موبایل

## قالب داده

```csv
مبدأ,مقصد,مقدار
فروش,تولید,۱۲۰
تولید,مالی,۸۰
مالی,فروش,۶۵
```

```json
[{"source":"فروش","target":"تولید","value":120}]
```

هر مقدار باید مثبت و متناهی باشد؛ سقف ۱۰۰۰ ارتباط و ۶۰ گروه است. در نمودار معمولی، ارتباط‌های رفت و برگشت یک نوار مشترک دارند. مقدار هر گروه مجموع ارتباط‌های ورودی و خروجی آن است و حلقه خودی یک بار شمرده می‌شود. نمودار جهت‌دار هر جهت را مستقل نشان می‌دهد و حلقه خودی در دو سر شمارش می‌شود. درصد گروه بر اساس مجموع مقدارهای گروه‌ها محاسبه می‌شود؛ کارت مجموع مقدار، مجموع ردیف‌های داده است.

فونت سفارشی تا ۳ مگابایت و داده تا ۲ مگابایت مجاز است. فونت در پروژه دانلودی ذخیره می‌شود؛ تنها فونت‌هایی را استفاده و توزیع کنید که مجوزشان را دارید. برای SVG و تصویر، وزیرمتن یا فونت سفارشی جاسازی می‌شود. فونت‌های سیستمی Tahoma و Arial وابسته به دستگاه دریافت‌کننده‌اند. تصویرهای بیش از ۴۰ میلیون پیکسل محدود می‌شوند.

داده‌ها و فونت در localStorage مرورگر ذخیره می‌شوند. هیچ داده‌ای به سرور ارسال نمی‌شود. برچسب‌های خیلی بلند یا تعداد بالای گروه‌ها ممکن است هم‌پوشانی داشته باشند؛ اندازه بوم را افزایش دهید یا اندازه فونت را کاهش دهید.
