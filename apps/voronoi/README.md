# ورونوی استودیو

وب‌اپ فارسی و راست‌به‌چپ برای ساخت Voronoi Treemap وزنی و سلسله‌مراتبی، با الهام از ساختار و سبک [سانکی استودیو](https://sankey-studio.vercel.app/).

## اجرا

نیازمند Node.js نسخهٔ ۲۰٫۱۹ یا جدیدتر:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

## امکانات

- جدول قابل ویرایش، افزودن و حذف ردیف، بازگشت داده و نمونهٔ آماده
- ورود CSV، JSON و Excel با ستون‌های نام، گروه و مقدار (یا name، group، value)
- پذیرش اعداد فارسی و عربی، اعشار فارسی و جداکنندهٔ هزارگان
- گروه‌بندی دو سطحی، ورود به گروه و راهنمای تعاملی سلول‌ها
- بوم دایره، مستطیل و شش‌ضلعی؛ چهار پالت، رنگ اختصاصی هر ردیف و مرزها
- عنوان، توضیح، واحد، اندازهٔ نوشته، نمایش مقدار و درصد
- کنترل دقت، چیدمان تصادفی با بذر ثابت و نمایش خطای واقعی مساحت
- PNG با کیفیت ۱ تا ۳ برابر، SVG برداری، چاپ/PDF، CSV و پروژهٔ JSON
- ذخیرهٔ خودکار محلی، پوستهٔ روشن و تیره، بزرگ‌نمایی و تمام‌صفحه
- طراحی واکنش‌گرا و فونت وزیرمتن محلی

پردازش فایل‌ها کاملاً داخل مرورگر است؛ برنامه داده را به سرور ارسال نمی‌کند. سقف ورود ۱۵۰ ردیف و ۵ مگابایت است. گروه‌بندی از یک سطح گروه و یک سطح سلول پشتیبانی می‌کند. کتابخانهٔ d3-voronoi-treemap مساحت‌ها را به‌صورت تقریبی همگرا می‌کند؛ داده‌های بسیار نامتوازن ممکن است از دقت هدف فاصله داشته باشند و خطای واقعی روی صفحه نمایش داده می‌شود.

## فایل ورودی

```csv
نام,گروه,مقدار
مسکن,ضروری,۳۵
خواربار,ضروری,۱۸
پس‌انداز,آینده,۹
```

ستون color اختیاری است و رنگ شش‌رقمی مانند #147d70 می‌پذیرد. در Excel اولین برگه خوانده می‌شود؛ سطر نخست عنوان ستون‌هاست. CSV و JSON برای ورود مجدد داده مناسب‌اند؛ فایل پروژه، تمام تنظیمات را نیز نگه می‌دارد.

## استقرار

برای Vercel مخزن را Import کنید: Framework برابر Vite، فرمان build برابر `npm run build` و پوشهٔ خروجی `dist` است. `vercel.json` آماده است. خروجی `dist` روی هر میزبان فایل استاتیک قابل اجراست. برای GitHub Pages مقدار base در Vite باید متناسب با مسیر مخزن تنظیم شود.

SVG متن را به‌صورت برداری نگه می‌دارد و فونت وزیرمتن را در فایل جاسازی می‌کند؛ برخی ویرایشگرها ممکن است فونت جاسازی‌شده را نخوانند. PNG خروجی تصویری مستقل دارد. برای PDF، گزینهٔ چاپ را انتخاب کرده و در پنجرهٔ مرورگر Save as PDF را بزنید.

## مبنای محاسبه

[d3-voronoi-treemap](https://github.com/Kcnarf/d3-voronoi-treemap) و [d3-hierarchy](https://github.com/d3/d3-hierarchy). خطای نمایش‌داده‌شده برابر نصف مجموع قدرمطلق اختلاف سهم مساحت هر سلول با سهم مقدار آن است.

در محیط‌های محدود که اجرای پردازش فرزند مسدود است، `npm run build:portable` و `npm run test:portable` مسیر جایگزین بدون اجرای پردازش فرزند هستند.

## فونت دلخواه

در بخش طراحی، فایل WOFF/WOFF2/TTF/OTF (تا ۲ مگابایت) را بارگذاری کنید. فونت روی عنوان، توضیح و متن سلول‌ها اعمال می‌شود؛ چهار اندازه مستقل با لغزنده و ورودی عدد فارسی تنظیم می‌شوند. فونت در فایل پروژه JSON ذخیره و در SVG جاسازی می‌شود؛ بارگذاری پروژه و خروجی PNG/PDF نیز از فونت انتخابی استفاده می‌کنند. رابط برنامه برای خوانایی با وزیرمتن باقی می‌ماند. برای برگشت، فونت پیش‌فرض را انتخاب کنید. فایل فونت به سرور ارسال نمی‌شود؛ فونت بدون نویسه‌های فارسی ممکن است با فونت جایگزین نمایش داده شود.
